# Shared Packs

このディレクトリは、Proof Gate の共通 Quality Pack とデモ用 pack を置く場所です。

## 原則

- repo に置くのは共有可能な pack のみ
- 顧客固有 pack をそのまま置かない
- 追加する内容は匿名化・抽象化・デモ化する
- pack を更新したら CHANGELOG と version を更新する

## 既存ディレクトリ

- `customer_support_pack/`: 顧客対応AI向けの代表 pack
- `hr/`: HR / labor 系の pack ガイド
- `wiki/`: wiki / internal docs 系サンプル
- `demo_cycle/`: デモ・検証向け pack

詳細方針は `../docs/agents/quality-pack-spec.md` と `../docs/agents/asset-versioning.md` を参照してください。
