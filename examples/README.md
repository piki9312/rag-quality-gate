# Examples

このディレクトリは、Proof Gate の説明・検証・回帰確認に使うデモ例を置く場所です。

## 原則

- 例は demo または anonymized data のみを使う
- 顧客固有データ、実ログ、契約資料は置かない
- walkthrough や docs から参照される再現可能な最小例を優先する

## 既存例

- `demo-client-pack/`: クライアント説明用の小さな demo pack
- `vendor-poc-pack/`: ベンダー向け PoC 例
- `vendor-poc-pack-pass/`: PASS 状態の比較用例
- `external-rag-fixtures/`: adapter / schema の fixture
