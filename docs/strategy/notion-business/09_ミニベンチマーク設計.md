# 09_ミニベンチマーク設計

## 目的

- 公開FAQを使って、Proof Gateが「FAQ変更後の重大誤回答チェック」に向くことを短期間で示す
- ベンダーやエンド企業への営業時に、抽象論ではなくサンプル結果を見せる
- 業界別の重大誤回答パターン収集を始める

## 対象業界

- SaaS / ITサービス
- EC / サブスク
- 通信 / インフラ
- 人事 / 福利厚生 / 労務

## 対象文書

- 公開FAQ
- 利用規約の公開ページ
- 料金ページ
- 解約 / 返金ポリシー
- ヘルプセンター記事

## 規模

- 対象企業数: 3〜5社
- 合計質問数: 100〜150問
- 1社あたり: 25〜40問

## 質問数の配分例

| 区分 | 1社あたりの目安 |
|---|---|
| 料金 | 5〜8問 |
| 解約 | 5〜8問 |
| 返金 | 3〜5問 |
| 規約 / 例外条件 | 5〜8問 |
| サポート窓口 / エスカレーション | 3〜5問 |
| その他高リスク | 4〜6問 |

## 評価分類

| 分類 | 意味 |
|---|---|
| PASS | 文書根拠に沿って重大な問題なし |
| WARNING | 軽微な曖昧さがあるが直ちに重大事故ではない |
| FAIL | 重大誤回答または危険な欠落がある |
| NEEDS_REVIEW | 文書差分や解釈の確認が必要 |

## S1 / S2 / S3分類

| 重大度 | 定義 | 例 |
|---|---|---|
| S1 | 顧客被害、返金トラブル、契約誤認につながる | 返金不可を返金可と回答する |
| S2 | 運用上の混乱や説明責任問題につながる | 条件付き例外を落として回答する |
| S3 | 軽微な表現差や案内不足 | 窓口表現が曖昧 |

## 出力レポート項目

- 対象企業 / 対象文書
- 質問総数
- PASS / WARNING / FAIL / NEEDS_REVIEW件数
- S1 / S2 / S3件数
- 代表的な失敗パターン
- 業界ごとの注意論点
- 営業で使える要約コメント

## 営業資料への使い方

- 「FAQ更新後の事故はどの業界でも起こりうる」と説明する材料にする
- S1事例を1〜2件だけ抜粋して、重大誤回答のイメージを伝える
- ベンダー向けには「納品後の変更時チェック」価値の説明に使う
- エンド企業向けには「本番前リスク診断」の具体例として見せる

- [ ] 業界を2つに絞って先行着手
