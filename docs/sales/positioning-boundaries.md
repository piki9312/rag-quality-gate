# 売ってよい範囲 / 約束してはいけない範囲

## 言ってよいこと

- 指定された範囲で高リスク回答を診断します
- 文書更新後・prompt変更後・model変更後の品質劣化を検出する材料を出します
- NEEDS_REVIEW対象を可視化します
- 顧客向け / 内部運用向けの成果物を分けて出せます
- 既存RAG APIに adapter 経由で後付けできます
- リリース判断の証跡を残せます

## 言ってはいけないこと

- AI回答の安全性を保証します
- 誤回答を完全に防ぎます
- S1事故を防止できます
- PASSなら本番導入して問題ありません
- 法的適合性を保証します
- 全質問に対して正しいことを保証します

## PASS の説明

- PASS は「指定ケース・対象文書・指定モデル・指定設定で、今回の検査基準を満たした」という意味です。
- PASS は「全社運用で安全」「全質問で正しい」「事故が起きない」を意味しません。
- `mock / ci_mock` は simulation only です。
