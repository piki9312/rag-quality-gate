# 顧客データ取扱い説明（PoC向け1枚）

> この文書は正式な法務契約ではなく、Proof Gate PoC で想定しているデータ取扱いを説明するための実務資料です。必要に応じてNDA、個別契約、データ取扱い合意書とあわせて確認してください。

## 1. 取り扱うデータ

PoCでは、以下のデータを取り扱う場合があります。

- FAQ
- ヘルプページ
- 利用規約
- 料金表
- 社内文書
- 評価質問
- AI回答ログ

## 2. 利用目的

取り扱うデータは、主に以下の目的で利用します。

- RAG構築
- 評価ケース作成
- 回答品質評価
- Gate判定
- レポート作成

## 3. 外部API利用の有無

- 評価や回答生成の一部で、OpenAI 等の LLM API を利用する場合があります。
- その場合、API に送る可能性があるデータ範囲は、質問文、回答文、評価対象の文書断片、評価に必要なメタデータです。
- 顧客要望に応じて、マスキング、匿名化、送信範囲の制限、ローカル処理方針を検討できます。
- 外部APIを利用しない構成が必要な場合は、PoC開始前に前提条件を確認します。

## 4. 保存範囲

PoC期間中は、以下を保存する可能性があります。

- 文書
- 評価ケース
- 評価結果
- レポート
- ログ

保存場所、保存期間、アクセス権限は、PoC開始前に合意します。

## 5. 削除対応

- PoC終了後の削除方針は、開始前に合意します。
- 顧客要望に応じて、文書、評価ケース、評価結果、ログ、レポートの削除対応を行います。
- 削除対象と保持対象（例: 契約・請求・監査上必要な最小情報）は、個別に確認します。

## 6. 学習利用について

- 顧客データを無断でモデル学習に利用しません。
- 改善ノウハウを再利用する場合は、個別文書や個社固有情報が分からないように抽象化・匿名化した形で扱います。
- 顧客固有の文書、質問、回答例を、別顧客向け資料へ無断転用しません。

## 7. 注意事項

- 機密情報・個人情報を含む場合は、共有範囲と取扱い条件を事前に合意してください。
- 必要に応じてNDAやデータ取扱い合意を締結してください。
- 法務・セキュリティ要件がある場合は、PoC開始前に必ず提示してください。
